**Neural Network built from scratch using NumPy for handwritten digit classification.**
A fully connected neural network implemented from scratch in Python using only NumPy, without deep learning frameworks such as TensorFlow or PyTorch.

**## Features**

* Forward propagation
* Backpropagation
* Gradient descent optimization
* Multi-layer neural network architecture
* ReLU and Softmax activations
* Training and testing pipeline
* Accuracy evaluation on handwritten digit classification data

**## Tech Stack**

* Python
* NumPy
* Pandas
* Matplotlib

**## Project Overview**
This project demonstrates the core mathematics and implementation details behind neural networks. The model is trained on image data with 784 input features and predicts digit classes using a custom-built feedforward neural network.

**The goal of the project was to understand:**
* How neural networks learn
* Weight and bias updates through backpropagation
* Loss minimization using gradient descent
* Data preprocessing and model evaluation
**## Learning Outcomes**
Through this project, I gained hands-on experience with:
* Matrix-based neural network computation
* Implementing deep learning logic without frameworks
* Debugging training instability and parameter updates
* Understanding the fundamentals behind modern AI libraries
